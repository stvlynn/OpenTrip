title: Plan a trip
description: Build a shared itinerary with days, places, routes, and reservations.
---

## Work from the trip overview

The trip workspace brings the map and schedule together. Use the overview to
understand the whole route, then open a day when you need to make detailed
changes.

![A real OpenTrip desktop trip map with the shared itinerary beside it](/assets/screenshots/pc-map.jpg)

## Add useful stops

For each stop, add the place, expected time, category, and any note the group
will need on the day. Keep transport legs between cities explicit so the map
and itinerary tell the same story.

## Record reservations

Add confirmed lodging, transport, or activities as reservations. Put booking
references and time-sensitive notes on the reservation instead of scattering
them across chat messages.

## Keep plans honest

Treat uncertain ideas as proposals and confirmed bookings as commitments.
When a day becomes crowded, move or remove stops instead of relying on
overlapping times.

![The OpenTrip daily schedule used to review timing and stop order](/assets/screenshots/pc-schedule.jpg)

## Keep confirmations together

Reservations stay alongside the itinerary so the group can find lodging,
transport, and activity details without searching through old messages.

![OpenTrip reservations grouped by lodging, transport, and activity](/assets/screenshots/pc-reservations.jpg)
