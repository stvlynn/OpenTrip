## Open settings

Use the account menu to open **Settings**. Settings open as a dialog (not a
separate route) from the home hub or planner.

## Profile and avatar

- Update your display name.
- Upload or remove an avatar. Managed avatars use OpenTrip file storage so the
  same image appears for trip members.

## Default currency

Set a default currency for your account. Trip expenses still store the currency
you choose per expense; settle-up can display amounts in another currency via
FX conversion. See [Expenses](./expenses.mdx).

## Theme and language

Choose light or dark appearance and your UI language from the preferences
supported by the deployment. Copy is centralized in the product; switching
language updates labels across the SPA.

## Permissions

On mobile-capable browsers, review notification (and related) permissions from
settings. Grant only what you need for the features you use.

## About

The about section identifies the product build and links out to public
resources when configured.

## Security shortcuts

Password and 2FA controls live alongside account settings — follow
[Account and security](./account-and-security.mdx) for recovery and enrollment
steps.
