## Sign-in options

OpenTrip supports email and password, Google, and WeChat where configured.
Available providers can vary by deployment.

## Recover or change a password

From the sign-in screen, choose **Forgot password?** and complete the email
verification flow. Signed-in users can change or establish a password from
profile / security settings.

## Add two-factor authentication

1. Open security settings.
2. Enable 2FA (TOTP).
3. Scan the QR code with your authenticator app.
4. Save backup codes somewhere outside OpenTrip.
5. Verify a code before leaving the setup screen.

### If you lose access

1. Try a backup code if you still have the list.
2. If you cannot complete 2FA, use the account recovery path your deployment
   supports (typically email-assisted recovery). Contact the operator if you
   are locked out of the only enrolled device.

## Protect invitations and sessions

- Treat trip invites like private links; regenerate if exposed.
- Sign out on shared devices.
- Revoke access when a device may have been compromised.
